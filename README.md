# cardgame (가제)

친구들끼리 하는 2~4인 온라인 카드 대결 게임 cardgame(가제)의 **윈도우용 설치 파일과 게임 빌드만** 올려 두는 곳입니다. 소스 코드는 여기에 없습니다.

## 설치

1. [가장 최근 릴리스](../../releases/latest)에서 `cardgame-setup.exe`를 받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명을 하지 않은 프로그램이라 처음 한 번 뜹니다.
3. **설치**를 누르면 내 계정 폴더(`%LOCALAPPDATA%\Programs\cardgame`)에 설치되고 바탕화면과 시작 메뉴에 아이콘이 생깁니다. 관리자 권한은 필요 없습니다.
4. 그 뒤로는 아이콘으로 켜기만 하면 됩니다. 새 버전이 있으면 저절로 받고 게임이 켜집니다.

## 지우기

윈도우 **설정 → 앱 → 설치된 앱**에서 cardgame을 찾아 제거합니다. 저장(닉네임, 컬렉션, 덱)은 지울지 물어봅니다.

## 릴리스에 들어 있는 파일

| 파일 | 내용 |
| --- | --- |
| `cardgame-setup.exe` | 설치 파일이자 실행기입니다. 설치, 새 버전 받기, 게임 켜기, 지우기를 합니다. |
| `cardgame-<버전>-win64.zip` | 게임 빌드입니다. 실행기가 받아서 풉니다. |
| `manifest.json` | 버전, 바뀐 것, 파일 크기와 SHA-256입니다. 실행기가 이것을 보고 새 버전을 받습니다. |
